---
title: "Wan F4 quality and Cache-DiT"
description: "Compare cache-free and conservative grouped caching on Wan2.2 T2V A14B ModelSlim F4."
---

Wan2.2 T2V A14B ModelSlim F4 supports request-level quality controls:

| Explicit quality | Cache-DiT behavior |
| --- | --- |
| `exact` | Disabled, including when enabled by environment variables |
| `lossless` | Disabled; existing lossless fusion rules still apply |
| `high` | Conservative, independent layer-group caching |

Omitting `--quality` preserves legacy environment-controlled caching. `--enable-cache-dit false` disables caching in every tier. The tiers preserve the loaded checkpoint's precision; `exact` does not restore unquantized weights or guarantee correct subjects.

## Fixed-seed baseline

Start with the cache-free F4 model and ND weights:

```bash
SGLANG_NPU_ENABLE_MXFP4_NZ=0 \
ASCEND_RT_VISIBLE_DEVICES=0,1,2,3 \
sglang generate \
  --model-path ./Wan2.2-T2V-A14B-Diffusers-F4/ \
  --ulysses-degree 4 --num-gpus 4 --port 30088 \
  --warmup-mode request \
  --prompt "A cute happy Corgi playing in park sunset animated style" \
  --seed 0 --num-frames 81 --num-inference-steps 40 \
  --height 720 --width 1280 \
  --dit-cpu-offload false --pin-cpu-memory false \
  --quality exact --enable-cache-dit false
```

Run the same command with `--quality high` and remove `--enable-cache-dit false` to evaluate grouped caching. Explicit `high` uses preset defaults and request overrides, ignoring legacy cache tuning environment variables.

The experimental preset always computes layers 0–4 and 38–39. Middle groups are `[5,13)`, `[13,21)`, `[21,29)`, and `[29,37)`; layer 37 also computes because its final group has no cacheable middle. Each group computes its first and last layer. The high-/low-noise experts use thresholds 0.08/0.05, six expert-local warmup steps, at most one consecutive cached step, and no TaylorSeer or DMD. First/final two global steps and precision transitions force computation. Logs report effective precision and each group's compute/reuse counts.

Grouped caching currently requires eager, full-resolution execution and cannot be combined with TeaCache or Spectrum. Cache-DiT 1.3.5 supports the adapter; upgrading is not required. CPU lifecycle compatibility does not establish Ascend video quality or speed.

## Diagnostic precision controls

Keep `--quality exact --enable-cache-dit false` and compare one diagnostic at a time:

```bash
--modelslim-precision '{"linear":"W4A8"}'
--modelslim-precision '{"attention":"FLOAT"}'
```

W4A8 retains packed F4 weights and changes activation precision only; dual-scale MXFP4 is unsupported for this diagnostic. FLOAT attention uses the model's floating dtype. The default value for either control is `checkpoint`. Video API requests accept the same `modelslim_precision` object through their extra parameters or multipart JSON field.

The implicit single-scale MXFP4 schedule protects the first two and last two actual denoising steps. Explicit checkpoint timestep policies take precedence over this fallback.

## Layer overrides

`--cache-dit-params` accepts ordered, nonoverlapping, half-open ranges and existing cache knobs. Ranges must preserve the first five and final two layers. Uncovered layers always compute. Each cached group must compute at least its first and last layer.

```bash
--cache-dit-params '{"layer_groups":[{"start":5,"end":13,"residual_diff_threshold":0.04},{"start":13,"end":21}],"secondary":{"layer_groups":[{"start":5,"end":13,"residual_diff_threshold":0.03}]}}'
```

The secondary expert inherits primary request knobs unless overridden. With explicit `high`, its preset threshold remains 0.05 unless the request specifies a threshold. A secondary `layer_groups` list replaces the inherited primary ranges. Use `[]` to compute an expert's entire stack.

## Hardware acceptance

Compare cache-off F4, the original aggressive cache configuration, and grouped caching using identical prompts and seeds 0, 1, and 2. Include the Corgi and cowboy prompts, the exact failing clock prompt, and `A white clock` as a separate control. Compare ND/NZ and precision diagnostics separately.

Record hardware, CANN/torch_npu/operator versions, checkpoint provenance, sampler, flow shift, guidance values, expert boundary, initial latents, latency, peak memory, noise-prediction/latent differences, subject fidelity, flicker, and group reuse counts. Reject a caching setting that introduces subject substitutions or noticeable added flicker against cache-off F4.

The supplied reference command uses seed 0 and a different prompt and checkpoint layout. Its unavailable `vbench.py` defaults, `ALGO=3`, and `FAST_LAYERNORM=1` have no established SGLang equivalents. Reference parity requires inspecting that implementation and matching checkpoint descriptors, prompts, negative prompts, sampler settings, and initial noise.
